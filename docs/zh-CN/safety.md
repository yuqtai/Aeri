# 安全与已知限制

适用于 Aeri 0.4.0。[English](../safety.md)

## 权限和数据

- 桌面与浏览器控制可分别关闭。
- 后台执行者默认 **完全访问**，可以改文件、运行命令，不逐项确认；误识别也可能被执行。可改为“工作目录”或“只读”。Codex 使用其沙箱，Claude Code 使用工具权限，不同执行者的限制机制并不相同。
- 后台提示要求删除、发送消息、付款、提交表单等不可撤销操作前停止；这是提示词约束，**不是安全边界**。拿到任务返回文字不表示每个操作都验证成功。
- 任务内容通过标准输入传给 CLI，不拼成 shell 命令；取消会结束进程树。
- API Key 在 `%APPDATA%\VoiceAssistant\config.json` 中由 DPAPI 加密，当前 Windows 账户可解密。聊天和任务历史在本地保留 30 天，**不是 DPAPI 加密**，可能含敏感内容；可在“历史记录”查看、停存或清空。

唤醒检测始终在本地。标准模式使用本地识别时，首次下载模型后音频在本机识别，但转写、屏幕上下文、工具结果仍可能发给大模型。云识别和实时模式在激活后把音频发给所选服务，包括后续聆听轮次。“耳机直接插话”会在播报时保持收音，使用扬声器时应关闭以避免回声。请求受对应服务的计费和数据政策约束。

插件是文字，但会影响模型的工具调用，只应安装可信来源。`local_http` 限制 HTTP(S) 目标为本机回环；密钥占位符在本地解析，返回文本中的值被遮盖。这个限制只属于该工具，并不限制智能体的所有工具。见 [插件](plugins.md)。

## 手机控制

默认关闭，开启后仅接受本机或局域网地址。六位配对码有效五分钟，错五次失效；配对后用 256 位随机令牌，电脑端由 DPAPI 加密保存在 `remote.json`。连接本身**不加密**，音频、命令和回答只应在可信私人网络传输。可撤销全部配对。

## 桌面和浏览器限制

- 常规控件操作走无障碍接口，不动鼠标；模拟输入、快捷键和双击仍共享真实键鼠，期间避免同时操作。
- 普通权限程序不能操控管理员窗口；最小化窗口可能要恢复才能读取。自绘控件、弹出式下拉菜单不一定可可靠访问。
- 桌面组件拒绝部分系统快捷键；关闭应用、电源等有专用工具。关闭应用先正常请求，保存提示留给用户，受保护系统进程不关闭。
- `%USERPROFILE%\.agent-desktop` 必须仅当前用户可写。CLI 沙箱添加额外可写账户导致失败时，Aeri 会尝试修复额外权限后重试。
- 浏览器控制使用独立 Edge 会话，没有日常浏览器登录状态；需要 Node.js/npx 和 Playwright MCP。网站搜索快捷操作则在用户自己的浏览器打开结果。
- 文件查找先用 Windows 搜索索引；无索引时扫描常用目录，不是搜索每块盘的所有目录。
- 剪贴板历史只记录运行期间复制的文字且只在内存；聊天/任务历史是另一项持久功能。
- 夜间模式、勿扰模式打开系统设置页；亮度通常只支持内置屏幕。

## 语音与任务限制

本地识别首次需要联网下载、磁盘空间和 Windows `tar.exe`。识别语言跟随应用语言，不是自动多语种识别。标准播报只能使用 SAPI 可枚举的音色；安装了 Windows 自然音色不代表 SAPI 可见。实时和云识别需要服务网络及 Key；语音不可用时可打字，但模型对话仍需可用大模型。

噪声可能误唤醒或漏检，可调整灵敏度、改用快捷键。麦克风变更会自动处理；没有设备时定期重试。实时语音不走标准模式直达规则，文字仍走标准路径。使用配置的大模型回答时，实时服务提前产生的回复会被取消。

一次只运行一个后台任务。续接上下文只在本次运行期间有效，持久历史保留结果但不恢复任务。异常、空回复和步骤超限会报错，重要结果仍需自行核对。

## 尚需实机验证

旧版记录没有完成真实麦克风插拔、真正重启后的自启、多显示器/混合 DPI 光球、Wi-Fi/蓝牙/亮度/主题/电源实际切换验证。曾记录模拟输入后第一次点击偶尔无效，尚未确认实体键盘或粘贴是否复现。大音量外放下真人唤醒打断仍需实际说话测试。这些保留为待验项目，不代表 0.4.0 已测过这些路径。
