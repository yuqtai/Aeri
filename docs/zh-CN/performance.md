# 性能与历史实测

架构说明适用于 0.4.0；以下数字来自旧版记录，**不是 0.4.0 的新测试结果**。[English](../performance.md)

## 资源开销来自哪里

Windows 主程序使用 Rust 和 Slint 软件渲染，待机时停止界面动画。唤醒模型在本地运行，前面有能量门限。agent-desktop 只在桌面操作时启动，Codex、Claude Code、浏览器控制按需启动。

0.4.0 新安装默认标准模式、本地离线识别。识别模型首次使用另行下载，不在 ZIP 内；加载识别模型、本地大模型、浏览器或后台智能体会增加 CPU 和内存。旧的待机数据没有覆盖这条新识别路径。

标准模式支持的常用命令可走本地直达规则，不等待大模型；文件、音量、窗口、截图、提醒、计算和状态有专用工具。其他请求还包含识别、网络、大模型思考、工具和播报时间。实时语音由所选服务负责听说，通常由所选大模型思考；语音请求不走标准模式的直达规则。

## 旧版记录

来源为项目改版前的性能文档。机器：AMD Ryzen 5 5600（6 核 12 线程），16 GB 内存，Windows 11 专业版。待机测试使用 **Aeri 0.3.1 发布版**，只显示悬浮球、开启唤醒，连续五分钟。

| 项目（0.3.1） | 记录值 |
|---|---|
| 私有内存 | 61–62 MB；工作集约 105 MB |
| CPU | 单核 1–2%，整机约 0.1–0.2% |
| 常驻主程序 | 1 个，桌面组件临时启动 |

以下速度来自同一份 0.3.1 记录，每项三次取中位数，不含网络和模型思考；更新项包含下载和重启。

| 操作 | 记录值 |
|---|---|
| 计算、时间、应用查找、文件信息、电脑状态 | 小于 1 ms |
| 读当前窗口文字（screen_read） | 约 46 ms |
| 桌面组件列窗口 | 约 175 ms |
| Windows 索引按文件名搜索 | 约 0.6 秒 |
| 编辑器完整控件快照 | 约 0.7 秒 |
| MCP 启动至首次应答 | 27 ms |
| 应用内更新（下载 22 MB、校验、替换、重启） | 约 9 秒 |

包大小另测于 **0.3.5**：ZIP 24.2 MB，解压 55.6 MB（主程序 24.4 MB、桌面组件 3.3 MB、DLL 21.4 MB、唤醒模型 5.2 MB、手机 App 1.3 MB）。不能用作 0.4.0 下载或安装大小。

## 如何重测 0.4.0

记录版本、硬件、Windows 版本、语音模式与服务、已加载模型，以及是否计入浏览器和后台进程。分开测待机、首次模型下载/加载、识别和任务执行，多次运行，区分本地工具耗时与网络/模型耗时。本页没有提供新的 0.4.0 占用或延迟数据。
